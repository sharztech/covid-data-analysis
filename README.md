# COVID-19 Data Analysis & Streamlit Dashboard

## Project Overview

A self-guided data analysis project using COVID-19 data from **Our World in Data (OWID)** to develop practical Python, data analysis and visualisation skills.

The project follows an **ETL-style workflow**, loading, cleaning and transforming raw CSV data before analysing and visualising the results. The analysis was completed in Jupyter Notebooks and developed into an interactive **Streamlit dashboard**.

I used YouTube tutorials, open-source resources and AI-assisted learning to understand unfamiliar Python libraries, functions and programming concepts and apply them independently.

## Data Source

COVID-19 data from **Our World in Data (OWID)**, with the analysis focused on the **United Kingdom**.

## Project Workflow

**Extract → Transform → Analyse → Visualise → Communicate**

* **Extract:** Loaded the OWID COVID-19 CSV dataset into Python.
* **Transform:** Cleaned and prepared the raw data using Pandas and NumPy.
* **Analyse:** Explored UK COVID-19 data and investigated selected questions and hypotheses.
* **Visualise:** Created graphs using Matplotlib to identify and communicate trends.
* **Communicate:** Documented the findings and developed an interactive Streamlit dashboard.

## Project Structure

### `data/`

Contains the cleaned dataset used for analysis.

### `notebooks/`

**`uk_analysis.ipynb`**
Main analysis notebook containing data preparation, analysis and visualisations.

**`uk_findings.ipynb`**
Contains the written conclusions and findings from the analysis.

### Streamlit Dashboard

An interactive dashboard developed using the processed data to present the analysis and visualisations in an accessible format.
